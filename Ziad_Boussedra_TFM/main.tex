% --- Layout hygiene -------------------------------------------------
% `parskip` makes inter-paragraph glue elastic; `book` defaults to
% \flushbottom, which stretches that glue to force every page to the same
% height. On pages with few paragraphs (e.g. around a float) that produces
% very large, ugly gaps. \raggedbottom lets short pages simply end short.
